# Oracle APEX

Esta carpeta contiene los recursos relacionados con el desarrollo de la aplicación Oracle APEX del proyecto **FRAMED**.

## Descripción

La aplicación fue desarrollada utilizando Oracle Application Express (Oracle APEX) como plataforma Low-Code y Oracle Database como sistema gestor de bases de datos.

El desarrollo corresponde al prototipo funcional del sistema de información para la gestión y trazabilidad de establecimientos farmacéuticos del departamento de Antioquia.

## Contenido

- Exportación de la aplicación Oracle APEX (.sql).
- Capturas de las principales páginas del sistema.
- Evidencias del desarrollo.
- Recursos asociados al proyecto.

## Evidencias del prototipo

Las imágenes incluidas en esta carpeta muestran el avance funcional del sistema desarrollado en Oracle APEX, incluyendo las principales interfaces del proyecto FRAMED.
