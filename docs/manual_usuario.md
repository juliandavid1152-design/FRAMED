# Manual de Usuario

## Proyecto

**FRAMED**  
Fortalecimiento de la Regulación, Administración y Monitoreo de Establecimientos Farmacéuticos

---

# 1. Introducción

El presente manual tiene como finalidad orientar a los usuarios en el uso del sistema FRAMED. Describe las funcionalidades principales de la aplicación, la navegación entre módulos y el procedimiento general para realizar las operaciones más importantes.

FRAMED fue desarrollado para apoyar la gestión de los establecimientos farmacéuticos del departamento de Antioquia, centralizando el registro de establecimientos, reportes y novedades en una única plataforma.

---

# 2. Ingreso al Sistema

El acceso a la aplicación se realiza mediante autenticación de usuario.

Cada usuario dispone de credenciales personales para ingresar al sistema de acuerdo con los permisos asignados.

---

# 3. Menú Principal

El menú principal permite acceder a los diferentes módulos de la aplicación.

Los módulos disponibles son:

- Dashboard
- Establecimientos
- Reportantes
- Reportes
- Novedades
- Servicios
- Municipios
- Catálogos
- Administración

---

# 4. Gestión de Establecimientos

Este módulo permite administrar la información de los establecimientos farmacéuticos.

Las principales funciones son:

- Registrar establecimientos.
- Consultar establecimientos.
- Actualizar información.
- Consultar historial.

---

# 5. Gestión de Reportantes

Permite registrar y consultar la información de las personas responsables del envío de reportes.

Las operaciones disponibles incluyen:

- Registrar reportante.
- Editar información.
- Consultar registros.

---

# 6. Gestión de Reportes

Desde este módulo es posible registrar los reportes generados por los establecimientos farmacéuticos.

Cada reporte queda asociado a:

- Establecimiento.
- Reportante.
- Estado del reporte.
- Fecha de registro.

---

# 7. Gestión de Novedades

Permite registrar las novedades relacionadas con cada establecimiento.

Entre ellas se encuentran:

- Cambio de director técnico.
- Cambio de propietario.
- Cambio de razón social.
- Cambio de teléfono.
- Cambio de correo electrónico.
- Suspensión de servicios.
- Cierre temporal.
- Cierre definitivo.
- Modificación de horarios.

---

# 8. Consultas

El sistema permite realizar búsquedas utilizando diferentes criterios.

Por ejemplo:

- Nombre del establecimiento.
- NIT.
- Municipio.
- Estado.
- Director técnico.

---

# 9. Validaciones

Durante el registro de información el sistema realiza validaciones automáticas.

Entre ellas:

- Campos obligatorios.
- Integridad referencial.
- Valores duplicados.
- Formatos de datos.

---

# 10. Recomendaciones

Para garantizar el correcto funcionamiento del sistema se recomienda:

- Mantener actualizada la información.
- Verificar los datos antes de guardar.
- Utilizar únicamente usuarios autorizados.
- Cerrar sesión al finalizar la jornada.

---

# 11. Cierre de Sesión

Al finalizar las actividades el usuario deberá cerrar la sesión utilizando la opción correspondiente del menú principal.

Esta práctica ayuda a proteger la información del sistema y evita accesos no autorizados.

---

# 12. Soporte

En caso de presentarse inconvenientes técnicos, el usuario deberá comunicarse con el administrador del sistema o con el equipo encargado del soporte técnico para la atención del incidente.
