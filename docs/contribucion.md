# Guía de Contribución

## Objetivo

Definir la forma en que los integrantes del proyecto deberán contribuir al desarrollo del sistema.

---

## Flujo de trabajo

1. Crear una nueva rama.
2. Desarrollar la funcionalidad.
3. Realizar pruebas.
4. Crear Commit.
5. Crear Pull Request.
6. Revisar cambios.
7. Integrar a main.

---

## Convención de Commits

- feat:
- fix:
- docs:
- refactor:
- test:
- chore:

---

## Buenas prácticas

- Documentar el código.
- Mantener nombres descriptivos.
- Evitar duplicidad.
- Mantener consistencia.
