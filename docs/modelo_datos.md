# Modelo de Datos

## Entidades principales

- DT
- ESTABLECIMIENTO
- SERVICIOS
- ESTABLECIMIENTO_SERVICIO
- MUNICIPIOS
- ESTADO
- REPORTANTE
- REPORTES
- ESTADO_REPORTE
- NOVEDADES
- TIPO_NOVEDAD

---

## Relaciones

- Un director técnico puede estar asociado a varios establecimientos.

- Un establecimiento pertenece a un municipio.

- Un establecimiento puede prestar varios servicios.

- Un establecimiento puede registrar múltiples reportes.

- Un reporte puede contener múltiples novedades.

- Cada novedad pertenece a un tipo de novedad.
