# Matriz de Trazabilidad de Requerimientos

## Objetivo

La matriz de trazabilidad permite verificar que cada requerimiento funcional del sistema FRAMED se encuentre relacionado con un caso de uso, un componente del sistema y una prueba de validación.

---

| Requerimiento | Descripción | Caso de Uso | Módulo | Caso de Prueba | Estado |
|---------------|-------------|-------------|--------|----------------|--------|

| RF-02 | Consultar establecimientos | CU-02 | Establecimientos | CP-03 | Implementado |

---

## Beneficios

- Facilita el seguimiento del desarrollo.
- Permite identificar rápidamente qué requerimientos fueron implementados.
- Garantiza cobertura durante las pruebas.
- Facilita la documentación del proyecto.
- Mejora el mantenimiento del sistema.

---

## Observaciones

Esta matriz deberá actualizarse durante futuras iteraciones del proyecto conforme se incorporen nuevos requerimientos funcionales y no funcionales.
