# Diccionario de Datos

Este documento describe las tablas principales del proyecto FRAMED.

## DT

Información de directores técnicos.

## ESTABLECIMIENTO

Información general de establecimientos farmacéuticos.

## SERVICIOS

Servicios farmacéuticos disponibles.

## ESTABLECIMIENTO_SERVICIO

Tabla intermedia para relación muchos a muchos.

## REPORTANTE

Usuarios que generan reportes.

## REPORTES

Registro de reportes enviados.

## NOVEDADES

Detalle de novedades reportadas.

## TIPO_NOVEDAD

Catálogo de tipos de novedades.

## MUNICIPIOS

Municipios del departamento de Antioquia.

## ESTADO

Estados de establecimientos.

## ESTADO_REPORTE

Estados de los reportes.
