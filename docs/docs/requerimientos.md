# Requerimientos del Sistema

## Requerimientos Funcionales

RF-01. Registrar establecimientos farmacéuticos.

RF-02. Consultar establecimientos registrados.

RF-03. Editar información de establecimientos.

RF-04. Registrar reportes.

RF-05. Registrar novedades asociadas a un reporte.

RF-06. Consultar historial de novedades.

RF-07. Gestionar directores técnicos.

RF-08. Gestionar municipios.

RF-09. Gestionar servicios farmacéuticos.

RF-10. Gestionar estados de reportes.

---

## Requerimientos No Funcionales

RNF-01. El sistema debe ejecutarse sobre Oracle APEX.

RNF-02. La base de datos será Oracle Database.

RNF-03. El sistema deberá garantizar integridad referencial.

RNF-04. La aplicación deberá registrar auditoría de cambios.

RNF-05. La interfaz deberá ser responsive.

RNF-06. Los usuarios deberán autenticarse antes de acceder al sistema.
